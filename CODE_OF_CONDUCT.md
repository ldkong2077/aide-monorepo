# Code of Conduct

## Our Pledge

We are committed to making AIDE a welcoming, respectful, and useful open-source project for people with different backgrounds, skill levels, and ways of working.

## Expected Behavior

- Be respectful and constructive.
- Assume good intent, especially when helping non-professional programmers.
- Give feedback that is specific, actionable, and focused on the work.
- Respect privacy and do not request or share secrets, private keys, proprietary code, or personal data in public issues.

## Unacceptable Behavior

- Harassment, threats, insults, or discriminatory language.
- Publishing private information without permission.
- Repeated disruptive behavior after maintainers ask you to stop.
- Security reports posted publicly before coordinated disclosure.

## Enforcement

Maintainers may remove content, close issues, suspend discussion, or block contributors who violate this code of conduct. Security issues should follow [SECURITY.md](SECURITY.md).

## Reporting

Report conduct concerns through GitHub issues if public discussion is appropriate, or contact the maintainers privately using the security/contact channels listed in this repository.
